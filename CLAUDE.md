- Always record every change in `docs/*` (new or updated file, with a dated entry in that file's
  change log). Do this in the same piece of work as the change, not afterwards.
- Keep track of the architecture of the application in `docs/architecture.md`.
- Also add tests for all testable changes.
- The app colorscheme lives in `docs/colorscheme.md` (swatches in `docs/colorscheme.jpeg`). Use
  those tokens; do not introduce ad-hoc colors. If a color changes, update that file first.
